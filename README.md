# 🌌 Neo Analytics v1.0 — Intelligent Full-Stack Data Platform

Neo Analytics is a futuristic, ultra-fast data analytics and visualization web application built using **Lovable.dev**. By executing all data parsing and mathematical calculations entirely client-side, the platform guarantees sub-second processing speeds with zero server lag, rendering massive datasets smoothly at 60+ FPS via WebGL hardware acceleration.

👉 link : https://neoanalytics.lovable.app

---

## 🚀 Core Architectural Innovation: Adaptive Personas

Instead of a static dashboard, Neo Analytics features a **Workspace Mode** selector in the top navigation bar that dynamically reconstructs the entire UI/UX layout and adjusts the core processing engine to serve three distinct user archetypes:

### 🏡 1. Household & Budget Mode (General Public)
* **Target Audience:** Non-technical consumers looking to track personal finance.
* **Smart Detection:** Automatically scans uploaded sheets for finance headers like `Salary`, `Income`, `Rent`, or `Expenses`.
* **Visuals:** Simplified, highly intuitive 2D Pie and Bar charts tracking personal savings rates and monthly expense breakdowns.
* **AI Behavioral Shift:** The integrated chatbot transforms into a friendly personal finance coach, offering plain-English budget advice and tactical savings suggestions.

### 🔬 2. Research & Analytics Mode (Data Scientists & Students)
* **Target Audience:** Academic students, university freshers, and statistical researchers.
* **Academic Alignment:** Grouped metrics mapped directly to university syllabus topics (*Measures of Central Tendency*, *Probability Distributions*, *Hypothesis Testing*).
* **Advanced Engineering:** Unlocks a high-performance 3D visual canvas (Scatter/Bar plots), advanced probability distribution models, confidence interval computations, and an interactive hypothesis testing wizard (Null $H_0$ vs Alternative $H_1$).
* **Educational Tools:** Includes "Show Your Work" step-by-step formula dropdowns, rookie-friendly statistical tooltips, a "What-If" data outlier simulator slider, and one-click PDF academic lab report exports formatting data into structured *Aim, Apparatus, Observation, and Inference* columns.

### 💻 3. Developer & Systems Mode (Software Engineers)
* **Target Audience:** System architects, backend engineers, and tech recruiters.
* **Performance Control:** Brings data processing pipelines to the front. Monitors memory usage and sub-second file parsing execution benchmarks.
* **Data Streaming:** Features a live WebSocket stream simulator feeding dummy IoT/market data at 1-second intervals to prove system stability under heavy data loads.
* **Production Tools:** Houses an interactive SQL query generator and a "Developer API" panel outputting copy-pasteable Python (`requests`) and JavaScript (`fetch`) system endpoint snippets.

## 🤖 Mode-Aware AI Chatbot Overhaul

The platform features an advanced, floating AI Chatbot completely overhauled to solve native visualization limitations:
* **Flawless Markdown & Syntax Highlighting:** Integrated with explicit block parsing components. Programming strings like `def clean_data():` or raw statistical syntax are rendered inside beautiful, isolated dark-themed code blocks with a native "Copy Code" button.
* **Context-Driven Vocabulary:** The chatbot tracks the active workspace persona in real-time. It seamlessly speaks like a casual financial coach in Budget Mode, a rigorous math professor in Research Mode, or a senior backend architect in Developer Mode.

## 🛠️ Technology Stack

* **Development Engine:** Lovable.dev (AI Full-Stack Development Platform)
* **Frontend Framework:** React.js with TypeScript (for absolute state stability and strict type safety)
* **Styling & UI:** Tailwind CSS & Shadcn UI (Cyberpunk / Deep Midnight-Black dark-mode theme)
* **2D Graphics Engine:** Chart.js / Recharts
* **3D Rendering Canvas:** Three.js / Plotly.js (WebGL hardware-accelerated rendering)
* **In-Browser ML Engine:** TensorFlow.js (Runs client-side linear and polynomial trend regressions live)
* **Data Parsers:** PapaParse / SheetJS (For serverless client-side file reading)
